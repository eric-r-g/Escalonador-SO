# Escalonador-SO

Um simulador de escalonador de um sistema operacional, aplicando as principais técnicas existentes.

## Dependências

- g++
- Make
- Node.js
- Vite
- mui
- cpp-httplib

## Como utilizar

O programa é composto de duas partes: Front-end e Back-end. Para executar o Back-end basta entrar na pasta _Back_ e executar

```sh
make run
```

Já para executar o Front-end você deve entrar na pasta _Front/escalonator_ e executar

```sh
npm install
```

E, logo após todas as dependências terem sido instaladas,

```sh
npm run dev
```

Finalmente, você poderá utilizar a interface web acessando o link _http://localhost:5173/_ no seu navegador.
